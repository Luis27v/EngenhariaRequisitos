# Atividade 01 - Engenharia de Requisitos


**Situação Problema**:
---

- Desafio - Problema
- Escola necessitando sistema de controle de alunos
- Levantamento de Requisitos

--- 


**Perguntas**
<div align = "left">

1. **Quem utilizará o sistema?**

+ O sistema será utilizado por uma escola com o objetivo final de controlar o acesso e a saída de seus alunos ao ambiente escolar.


2. **Requisitos funcionais do Sistema:**

+ Controlar o Acesso e a Saída dos alunos.

+ Utilizar um sistema de carteirinhas digitais ou FaceID para controle de acesso

+ Cadastro de Alunos por parte de atores administrativos(Diretores, Secretaria, Porteiros e etc.)


3. **Requisitos Não-funcionais do Sistema:**

+ Criar relatórios com base na quantidade de alunos acessados diariamente 

+ Automaticamente lançar no sistema as faltas com base no horário dos registros


4. **Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.**

+ A importância de levantar requisitos é ter clareza no momento de criar um sistema, tornando o mais elaborado.
